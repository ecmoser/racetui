# Overall Vision:

Make a TUI that can fetch and diplay the calendars for various racing series from all around the world, and eventually link active races for streaming and use any public apis to fetch and display data about live sessions in the TUI.

## Calendar

The first priority for the project; I want this to include as many professional racing series as possible, and include the ability to add favorites and filter based off car style, time, series, etc.

Also, include links to live events that have livestreams so they can easily be opened. Make it easy to tell which are free and which are paid to watch.

Get this fully functional and polished before even thinking about the second part of the project.

## Live data

When and only when the calendar is fully functional and polished, implement live track maps/leaderboards/timing pages for any series that provide them via free APIs. 

Ex: F1 provides live track maps: implement that in the tui so that it shows drivers circulating around the track.
